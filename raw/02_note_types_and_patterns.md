# 02. 物件類型與 4K 基礎鍵型術語

## 1. 兩種基本物件（Note Types）
- **Rice（單鍵 / 米粒）**：最基礎的點擊物件，玩家只需在物件抵達判定線時按下對應按鍵即可完成判定。
- **Long Note（LN / 長條）**：具有「起點（Head）」與「終點（Tail）」的持續性物件。玩家必須在起點按下按鍵並持續按住，直到終點抵達判定線時才放開按鍵。在 osu!mania 的判定機制中，LN 的放開時機（Release Timing）同樣計算準度，過早或過晚放開都會導致判定降級（如 300 降為 200 或 100）。

## 2. 同時按壓類鍵型（Chord Patterns）
依據同一時間點出現的物件數量，分為四種基礎密度階梯：
- **Single（單點）**：同一時間點只有 1 個物件，適合呈現單音旋律或入門難度。
- **Jump（雙押）**：同一時間點有 2 個物件，通常用於強調重拍（如底鼓配小鼓）或和弦主音。
- **Hand（三押）**：同一時間點有 3 個物件，需要單手同時按下兩鍵、另一手按一鍵，常見於高潮副歌或重音爆發。
- **Quad（四押）**：同一時間點 4 條軌道全滿，屬於最高強度的重音強調，在入門與進階難度中應謹慎使用。

## 3. 連續移動類鍵型（Stream & Jack Patterns）
- **Stream（交互 / 樓梯連打）**：物件在連續的細分拍點（如 1/4 藍線）上於不同軌道間交替出現，玩家需透過左右手輪流點擊完成，講求手指協調性與讀譜流暢度。
- **Trill（雙鍵交互 / 震音）**：物件在兩條固定軌道之間快速來回交替（例如 `1-2-1-2` 或 `2-3-2-3`）。
- **Jack（同軌連打 / 縱連）**：物件在連續拍點上重複出現在「同一條軌道」（例如 `1-1-1`），考驗單指的爆發力與耐力。連續超過 3 個以上的快速同軌連打稱為 Long Jack，對新手極度不友好。

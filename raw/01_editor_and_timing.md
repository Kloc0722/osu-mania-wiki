# 01. osu!mania 4K 編輯器介面與 Timing 紅線基礎

## 1. 軌道結構與鍵位對應
osu!mania 4K 模式由 4 條垂直下落軌道組成，由左至右依序編號為 Column 1 至 Column 4（在 `.osu` 檔案中的 X 座標分別對應 `64`, `192`, `320`, `448`）。玩家預設按鍵通常配置為 `D`、`F`、`J`、`K`。物件（Notes）會由螢幕上方依照時間軸向下移動，當物件抵達底部的「判定線（Judgement Line）」時，玩家必須精準按下對應按鍵。

## 2. 節拍細分線（Beat Snap Divisor）
在作圖編輯器中，時間軸上的水平橫線代表音樂的拍點刻度，顏色對應不同的節拍細分：
- **白色線（1/1）**：整拍（四分音符），每個小節（4/4 拍）共有 4 條白線，其中第一條較粗代表小節線。
- **紅色線（1/2）**：半拍（八分音符），常見於流行樂或搖滾樂的基本鼓點。
- **藍色線（1/4）**：四分之一拍（十六分音符），用於快節奏旋律或連打配置。
- **紫色線（1/3）**：三連音（十二分音符），用於三拍子律動或切分音。
- **黃色線（1/6）與橘色線（1/8）**：六連音與三十二分音符，多用於高難度譜面的高速裝飾音。

## 3. Timing 紅線（Uninherited Timing Point）
Timing 紅線是整張譜面的時間基準，決定音樂的真實速度與對拍起點：
- **BPM（Beats Per Minute）**：每分鐘節拍數，決定拍點之間的實際時間間隔。
- **拍長計算公式**：$$\text{Beat Length (ms)} = \frac{60000}{\text{BPM}}$$
  例如：當 $\text{BPM} = 150$ 時，每 1 拍（1/1 白線）的時間間隔為 $60000 / 150 = 400\text{ ms}$；1/4 藍線的間隔則為 $100\text{ ms}$。
- **Offset（偏移量，單位 ms）**：第一條白線（第一拍）在音訊檔中出現的時間點。作圖的第一步必須透過波形圖與節拍器確認紅線完全貼齊鼓點，否則整張譜面都會產生「音畫不同步（Off-sync）」。
